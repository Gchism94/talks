The key solution

Move required teaching onto an approved service.

Use ACCESS for the classroom CPU and GPU allocation. First test components, measure demand, then prove the teaching and recovery paths.

01

Test on campus AWS

CPU component testing only, using already-authorized UITS access.

02

Benchmark on free GPUs

Kaggle or free Colab measurements before piloting. Their quotas do not reserve a class.

03

Teach on ACCESS

A measured CPU + GPU request, target-system replay and readiness checks. CloudBank is a conditional managed option.

NAIRR Classroom remains an additional route for eligible instructor-led AI pilots; it is not an assumed award. Durable support, repositories, recovery and exports are part of the service.
