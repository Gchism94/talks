Proposed pilot: develop in a bounded notebook environment; evaluate approved assignments through a Codabench queue attached to reviewed ACCESS compute where permitted. Budget operators, isolated submission workers, durable storage and exports separately. Validate scheduling, network/container rules and real class load before promising this route. Keep code, scoring bundles, submissions and results portable; a leaderboard is not the full course grade.
