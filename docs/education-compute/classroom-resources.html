Classroom platforms¶

Compare bounded options for development, notebooks, scoring and demonstrations. Open each resource’s limits before choosing it. GPU access is variable; competition hosting is not a GPU notebook.

Classroom 50

Workable successor for GitHub Classroom assignment distribution, repositories, submissions, feedback and grading.

Access: Free, open-source assignment workflow · evaluate before adoption

Limits and sources

Fifty Foundation project and hosted app are not ours. Requires a Team/Enterprise organization; check education eligibility. No additional Codespaces compute; Actions grading has separate quotas. ACCESS remains the CPU/GPU classroom route.

Classroom 50: project and license · Classroom 50: prerequisites and education eligibility · Classroom 50: managing Actions cost · Codespaces · free personal-account quotas

Codabench

Prediction scoring, reproducible code benchmarks and common test environments.

Access: Free benchmark hosting; compute depends on queue

Limits and sources

Shared CPU scoring jobs ≤20 minutes. Organizers supply queues for code submissions and all GPU workers; no GPU notebook or whole-class reservation.

Codabench · free benchmark hosting and bounded CPU scoring · Codabench · organizer-supplied CPU / GPU workers · Codabench · shared and dedicated queues

Kaggle Community Competitions

Prediction-file competitions with live leaderboards; judged hackathons for open-ended projects.

Access: Free self-service hosts and participants

Limits and sources

Training happens elsewhere or in separately limited notebooks. Restricted-email competitions disable notebooks by default; community hosting has no hands-on support.

Kaggle · no-cost Community Competitions · Kaggle · competition access and notebook limits

CodeGrade

Programming labs with browser editing, immediate autograding and instructor feedback.

Access: Advertised free for courses ≤50 students

Limits and sources

Check free-plan execution/LMS limits and roster scope. No verified free GPU entitlement or campus deployment; grading records need approved retention.

CodeGrade · bounded free classroom autograding

ChaGrade

Challenge-linked individual/team homework and instructor grading beyond leaderboard scores.

Access: Adjacent project; current free entitlement unverified

Limits and sources

Live page labels version 0.1 / Work In Progress. Support, quotas and current Codabench integration need verification; not a ready college-wide baseline.

ChaGrade · challenge-linked classroom workflow

evaluate

EvalAI

Custom prediction/code evaluation and organizer-controlled remote workers.

Access: Hosted service paid; open-source self-hosting

Limits and sources

Hosted plans $125–850/month; remote evaluation $100/month plus own compute. Self-hosting requires funded staff, infrastructure and storage. No verified hosted free tier.

EvalAI · paid hosted challenge plans · EvalAI · open-source self-hosting

Access: Retired at end of 2025; successor available

New account required; leaderboards do not transfer automatically. Preserve submissions/results separately. Separate CodaLab Worksheets is not covered.

Access: Bounded free personal CPU quotas

Limits and sources

60 two-core hours/month, or 90 for verified students; storage quota and machine sizes matter. No generally available GPU; not continuous application hosting.

Checkpointed small-model GPU experiments and training for a competition.

Short shared notebooks, CPU analysis and opportunistic accelerator exercises.

Access: Base free tier remains available

Limits and sources

GPU access and resource/session limits fluctuate. Free Colab is separate from the closed new-signup education Pro offer; never promise class GPU availability.

mybinder.org

Small Python/R notebooks launched from a reproducible repository, including metadata/text workshops.

Access: Free ephemeral CPU sessions

Limits and sources

1–2 GB RAM; ten-minute idle shutdown; aims for ≤6 hours or one CPU-hour; 100 concurrent sessions per repo. Download work; no GPU or persistent workspace promise.

Lightning AI Studio

DS/MLIS notebook preparation and small tests within actual credit balance.

Access: One free CPU Studio; GPU credit amount and expiry vary

Limits and sources

Four-hour CPU restart boundary; first 10 GB storage free. Do not promise a fixed monthly GPU grant or count paid academic discounts as free compute.

Lightning AI · billing and storage scope · Lightning AI student documentation and free CPU workflow

Hugging Face ZeroGPU / Spaces

Short Gradio inference demos and model-behavior comparisons; static exhibits on free Static Spaces.

Access: Five GPU minutes/day for signed-in Free users

Limits and sources

Two own ZeroGPU Spaces only for eligible personal accounts ≥30 days old. Shared queues and Gradio constraints; organization hosting paid. Ordinary compute-backed Space creation also needs a paid plan.

Tiny CUDA kernel/compiler demonstrations independent of the Codabench workflow.

Access: 15 executions/month; bounded CUDA exercises

Limits and sources

Advertised T4 16 GB, five runs per 15 minutes; per-execution allowance is not GPU-hours. Existing October 8 verification, no reserved class capacity.

cuda.live · optional CUDA micro-exercises

Modal

DS: a small pinned training/inference run. MLIS: public-corpus OCR, embeddings or retrieval experiments.

Access: Conditional recurring credit · $30/workspace/month; three Starter seats

Limits and sources

Payment method required; GPU, CPU and memory share credits. Set explicit usage and net-spend limits. Shared Endpoints tokens cost extra. Academic grant is an application, not funding in hand.
