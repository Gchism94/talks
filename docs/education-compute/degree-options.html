Options by degree¶

Supplemental reference · Browse supplements · Current report

This earlier nine-degree comparison excludes cyber programs. The working group’s needs assessment covers the college and is not limited to this historical comparison. These are activity fits, not confirmed course adoptions. Free resources suit small, bounded work; larger workloads need a measured and approved route.

Degree Suitable small-work starting point When to move / change activity
BS Information Science Python / R / SQL labs, small-data models and short GPU experiments. Browser prototypes for the immersive emphasis. Large training, concurrent GPUs, high-memory data or immersive hardware are required. ACCESS CPU / GPU labs; NAIRR Classroom for AI courses; campus XR hardware.
MS Data Science Reproducible notebooks, tabular ML, sampled datasets and checkpointed deep-learning labs. Data exceeds RAM / storage, models exceed available VRAM, or jobs need long / distributed training. ACCESS for larger data and scheduled capacity; NAIRR Classroom for AI instruction.
MS Information Science ML subplan: notebook experiments. Human-Centered Computing: web prototypes and small public-data studies. Training or deployment must persist; studies need controlled data, full desktops or specialized devices. Managed ACCESS environments; NAIRR Classroom where the course teaches AI.
BA Emerging Technologies in Society Small public-text / network analyses, web development, digital storytelling and public portfolios. Live app backends, licensed social-media data, private participant records or large corpora are required. ACCESS for larger analysis or managed servers; retain institution-approved study tools.
BA Game Design Branching narratives, rules and interaction prototypes, browser playtesting and published HTML games. A project needs a full 3D engine, large assets, persistent multiplayer servers or VR headsets. Campus engine / device labs; evaluate allocated GPU desktops and server support.
BS Game Development Game logic, headless tests, small JavaScript games and browser-playable prototypes. Unity / Unreal desktop workflows, heavy 3D builds, rendering, VR or persistent multiplayer are required. Campus game / XR labs; ACCESS servers or GPU desktops after software and license checks.
BA Information Science & Arts Creative coding, interactive graphics, audio-visual sketches and web-based UX prototypes. Work needs high-end rendering, large media, installed creative software, XR devices or physical installations. Campus media / XR labs; allocated GPU or remote desktops where appropriate.
MA Library & Information Science Metadata cleaning, Python / R / SQL exercises, small text collections and static digital exhibits. A repository / ILS must run continuously, preservation storage must endure, or collections need access controls. Managed ACCESS teaching servers plus library systems; NAIRR Classroom for AI coursework.
PhD Information Methods coursework, pilot analyses, reproducible examples and small model feasibility studies. Dissertation work needs sustained GPU time, large-scale simulation, controlled data or durable services. ACCESS / appropriate NAIRR research requests for research; Classroom only for eligible instruction.

Use the platform directory for quotas and the needs tool for a planning scenario. Course-specific software, accessibility and assessment requirements still need course-lead review.
