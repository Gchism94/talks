Provider limits

GitHub Codespaces: 60 h / month on 2 cores; 90 h for verified students. 120 / 180 core-hours; 15 / 20 GB-month storage. Personal-account quotas; larger machines use hours faster. No generally available GPU.

Kaggle Notebooks: Weekly GPU quota varies. No reserved classroom seats. Short, checkpointed notebook jobs; check the account quota and session timer. GPU memory and saved disk constrain models and data.

GitHub Pages: Static sites up to 1 GB; public sharing on the free tier. HTML / CSS / JavaScript hosting. Code executes on the viewer’s device; no application server, database or cloud GPU.

p5.js Web Editor: Free creative coding; uses the student’s device. Browser graphics and audio; device performance still matters. This is not a remote rendering workstation or allocated GPU.

Twine: Free narrative authoring; export portable HTML. Runs in the browser or a local app. Keep backups of story files; this is not a cloud engine workstation.

cuda.live: 15 free GPU executions/month; small CUDA demonstrations only. CUDABench is unverified as a free host pending the intended service URL. Free Colab remains a variable-capacity fallback. Read the deck’s source panels and research record for policy boundaries. Rehearse account eligibility, actual capacity and data/model fit before adopting.
