GitHub Codespaces · Cloud CPU
60 h / month on 2 cores; 90 h for verified students. 120 / 180 core-hours; 15 / 20 GB-month storage. Personal-account quotas; larger machines use hours faster. No generally available GPU. Provider ↗

Kaggle Notebooks · Cloud GPU
Weekly GPU quota varies. No reserved classroom seats. Short, checkpointed notebook jobs; check the account quota and session timer. GPU memory and saved disk constrain models and data. Provider ↗

GitHub Pages · Cloud hosting
Static sites up to 1 GB; public sharing on the free tier. HTML / CSS / JavaScript hosting. Code executes on the viewer’s device; no application server, database or cloud GPU. Provider ↗

p5.js Web Editor · Browser creation
Free creative coding; uses the student’s device. Browser graphics and audio; device performance still matters. This is not a remote rendering workstation or allocated GPU. Provider ↗

Twine · Browser creation
Free narrative authoring; export portable HTML. Runs in the browser or a local app. Keep backups of story files; this is not a cloud engine workstation. Provider ↗

Codabench: competition hosting and bounded CPU scoring, with organizer-supplied workers for code / GPUs. Compare every researched resource and its limits ↗.

Use public or institution-approved teaching data. Check account eligibility, actual quota, software/data fit, simultaneous class access, exports and operating costs before adoption.
