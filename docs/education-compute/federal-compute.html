Federal platforms¶

Federal support can fund machines, data systems, workflow services or operator teams. It does not automatically give every instructor an account or reserved GPUs. These 32 selected families overlap; this is not a machine census.

Start with ACCESS for the proposed CPU + GPU classroom allocation. For research, match the work to batch pools, interactive services, data fabrics and mission-specific routes. OSPool’s opportunistic jobs differ from a live notebook service; PATh Facility credit eligibility differs from OSPool access.

IDSS/MESA: an operator/service grant is not a generic teaching entitlement. Confirm the actual service, present support, eligible users and underlying provider policy. MESA funding alone does not establish PATh credit eligibility.

OSG Open Science Pool (OSPool)

Independent text/image analyses, parameter sweeps, model evaluation and many short CPU/GPU jobs.

Access: Documented guest education notebook or facilitated full event accounts

Limits and sources

Guest four-hour timeout/files may be lost; full accounts usually end shortly after event. Interruptible fair share; complete/checkpoint jobs within 20 hours. No sensitive/proprietary data or classroom GPU reservation.

Funding: NSF PATh/IRIS-HEP + institutional/DOE in-kind contributions
