What the existing plan was missing

Many small jobs, not one big notebook

Add OSPool/PATh and checkpointed workflow execution for corpus processing, parameter sweeps and independent model evaluation.

Managed teaching environments

Map CloudBank Classroom, Jetstream2 course images, NRP hubs and eligible CyVerse apps separately from raw GPU allocations.

Inference as an API

NRP-hosted model APIs and requested NAIRR model/software access can support assignments without every student operating a GPU server.

Data-first services

MESA, NDP, FabAID, iDLab, BRIDGE and NSDF supply discovery, metadata, reusable workflows and cross-site access; their grants are not all compute accounts.

Object storage, caches and movement

OSN stores active data; OSDF/Pelican distributes it; Globus moves it. None automatically provides archive permanence or all operating costs.

Systems, networks and specialized hardware

Chameleon, CloudLab and FABRIC support systems/edge/distributed experiments and specialized hardware. Use only when the testbed purpose matches.

Campus delivery and staff funding

Open OnDemand, gateways, identity, orchestration, grant-funded facilitators and college operators make allocations teachable. Compute awards alone do not fund all of them.

Domain facilities and mixed funding

DOE, NASA and NIH add mission-specific routes. CC*/MRI can fund campus capability; AI Hubs and CyVerse/UArizona show why state, subscription and federal support need separate labels.

Next assessment: Assess CloudBank managed CPU Classroom first through general ACCESS; keep Jetstream2 as the controlled alternative when an operator and sufficient quota/storage are funded. Use NRP, MESA/CyVerse and OSPool as independently gated components; clarify PATh eligibility before relying on it.

Open the pilot assessment and interactive capacity model ↗

Two representative courses, 80 seats: 36,600 CPU SUs with effective shutdown controls; 516,600 for always-on student VMs; 617,400 for an always-on shared hub. An optional grouped GPU module adds 1,920 GPU-resource SUs. These Jetstream2 estimates do not establish CloudBank pricing, an award, reserved capacity or a tested classroom service.

Important funding distinctions: CyVerse’s core NSF awards ended in 2024, while UArizona Pro eligibility is supported by state TRIF. CILogon’s federally supported development transitioned to subscription-funded operations. NSF AI Infrastructure Hubs fund coordination, people and education; partners must fund compute infrastructure. IDSS awards fund service builders, not a generic instructor GPU quota.

Missing operating product: a college-supported teaching service that combines a funded resource, reproducible environment, class roster/login, grading/export workflow, support owner, measured capacity and a tested restore. The proposal remains to pilot two courses, measure actual load, and scale only after those requirements are met.

OSG Open Science Pool (OSPool)

Documented service; approval/limits apply

Funding: NSF PATh/IRIS-HEP + institutional/DOE in-kind contributions

Relationship: OSG consortium / PATh services

Entry route

Documented guest education notebook or facilitated full event accounts

Useful for

Independent text/image analyses, parameter sweeps, model evaluation and many short CPU/GPU jobs.

Boundary: Guest four-hour timeout/files may be lost; full accounts usually end shortly after event. Interruptible fair share; complete/checkpoint jobs within 20 hours. No sensitive/proprietary data or classroom GPU reservation.

Evidence and review limits

Selected map of 32 platform/service/funding families, with six named IDSS projects and eight missing categories. Sources are federal agency and provider/project documents. 34 Exa discovery queries requested 179 result slots across six research areas; these are not 179 independently verified sources. Forty-two source records were added to the report, with targeted live checks for core claims. Earlier commercial-platform records were not all reverified.

Funding does not prove user cost, current account entitlement, production maturity, perpetual operation or an open grant deadline. No accounts, allocations, model API calls, cloud charges or grant applications were created. MESA findings use public documentation; no internal proposal or personnel plan was published.

Proposal, not a service announcement. No CloudBank request, allocation, staffing appointment or pilot budget is approved by this site. Provider policies and proposed tests are separate from completed classroom evidence.
