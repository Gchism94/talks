Numbers are editable examples, not measured demand, provider credits or an award. No data is uploaded or saved by this tool. Enter counts and requirements only, never private records.

    How to use the estimate¶

    This is one representative workload envelope. For different CPU/GPU groups or multiple courses, export separate scenarios and review overlap before adding totals. Continuous services need uptime-based sizing beyond this per-run model. Storage capacity does not establish throughput, preservation or a backup service.

    The tool follows the benchmark helper’s runtime × workload × resource × allowance arithmetic. Use measured component results and size_access.py for the next sizing step, then confirm provider units, target replay and classroom checks. Neither the tool nor a selected evidence basis makes a request submission-ready.
